# What Is a Protocol?

A **protocol** is a set of rules that allows devices, applications, or systems to communicate and exchange data correctly. Protocols define how data is formatted, addressed, transmitted, received, secured, and checked for errors.

## Common Types of Protocols

| Protocol | Full form or purpose | Use |
|---|---|---|
| HTTP | Hypertext Transfer Protocol | Transfers web pages and API requests. |
| HTTPS | HTTP Secure | Transfers web data with encryption. |
| FTP | File Transfer Protocol | Transfers files between systems. |
| SFTP | Secure File Transfer Protocol | Transfers files through a secure connection. |
| TCP | Transmission Control Protocol | Delivers data reliably and in the correct order. |
| UDP | User Datagram Protocol | Sends fast data without guaranteed delivery. |
| IP | Internet Protocol | Addresses and routes packets between devices. |
| DNS | Domain Name System | Converts domain names into IP addresses. |
| DHCP | Dynamic Host Configuration Protocol | Assigns network settings automatically. |
| SMTP | Simple Mail Transfer Protocol | Sends email messages. |
| POP3 | Post Office Protocol version 3 | Downloads email to a device. |
| IMAP | Internet Message Access Protocol | Synchronizes email across devices. |
| SSH | Secure Shell | Provides secure remote system access. |
| SNMP | Simple Network Management Protocol | Monitors and manages network devices. |
| MQTT | Message Queuing Telemetry Transport | Sends lightweight messages from IoT devices. |
| WebSocket | Persistent two-way web connection | Supports real-time updates and dashboards. |

## Protocols in Data Analytics

Protocols are important when analysts collect data from websites, cloud systems, databases, sensors, and APIs. HTTPS protects API data, FTP or SFTP transfers files, TCP supports reliable database connections, and MQTT can send sensor data to an analytics platform. WebSocket is useful for real-time dashboards.

## Security

Analysts should prefer encrypted protocols such as HTTPS, SFTP, and SSH. Credentials must not be exposed in URLs or code, and data should be transferred only with permission.

## Conclusion

Protocols make communication between systems predictable and reliable. Understanding them helps data analysts collect, transfer, secure, and use data correctly.
