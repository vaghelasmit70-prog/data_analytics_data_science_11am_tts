# What Is Excel?

**Microsoft Excel** is spreadsheet software used to store, organize, calculate, analyze, and visualize data. It contains rows, columns, cells, formulas, functions, tables, charts, PivotTables, and data-cleaning tools.

## Important Excel Terms

- **Workbook:** An Excel file that can contain one or more worksheets.
- **Worksheet:** A single grid of rows and columns inside a workbook.
- **Cell:** The intersection of a row and column, such as `A1`.
- **Range:** A group of cells, such as `A1:D10`.
- **Formula:** An expression beginning with `=`, such as `=A1+B1`.
- **Function:** A built-in calculation such as `SUM`, `AVERAGE`, `IF`, or `XLOOKUP`.

## How to Create a Workbook

1. Open Microsoft Excel.
2. Select **Blank workbook** or choose a template.
3. Enter a clear file name and save it as an `.xlsx` file.
4. Add a title and record the data source and date.
5. Save regularly and create a backup when the data is important.

## How to Create and Manage a Worksheet

1. Select the plus sign to add a new sheet.
2. Double-click the sheet tab and give it a meaningful name.
3. Enter field names in the first row, such as Date, Product, Sales, and Region.
4. Keep one record per row and one variable per column.
5. Use **Format as Table** to add filters and consistent formatting.
6. Add or delete sheets using the sheet-tab menu.
7. Move or copy sheets when organizing the workbook.

## Excel Data Analytics Workflow

1. Import data from a file, database, web source, or API.
2. Clean missing values, duplicate rows, incorrect formats, and spelling differences.
3. Use formulas such as `SUMIFS`, `COUNTIFS`, `IF`, and `XLOOKUP`.
4. Create PivotTables to summarize data by category, time, or region.
5. Build charts and dashboards for trends and comparisons.
6. Check totals and document assumptions before sharing results.

## Advantages and Limitations

Excel is easy to learn, flexible, and useful for small and medium-sized analysis. Very large datasets, many simultaneous users, and complex automated pipelines may require SQL, Python, or a dedicated database and BI platform.

## Conclusion

Excel is a practical starting tool for data analytics. A well-organized workbook separates raw data, cleaned data, calculations, and reports so that analysis remains clear and reproducible.
